CORSA Embed Test Page

The embed below is loaded via a <script> tag with a data-corsa-public-id attribute. All settings (theme, chat visibility, header, etc.) are fetched automatically from the Corsa API — no additional configuration is needed on the host page.

Replace data-corsa-public-id with a real embed public ID.

Manual mount via JS API

You can also mount programmatically by targeting an existing element: 

<div id="corsa-stream-widget"></div>
<script src="bundle.js"></script>
<script>
  CorsaEmbed.mount({
    elementId: "corsa-stream-widget",
    publicId: "e3fcce22-6c1a-49af-ab63-df4850086b77"
  });
</script>
